# Formulário de Contato

Formulários template-driven em Angular

Atividade de **Interfaces Ricas** (IR) — IFRN.

## Stack

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white) ![Angular](https://img.shields.io/badge/Angular-DD0031?style=for-the-badge&logo=angular&logoColor=white)

## Como rodar

```bash
npm install
npm start
```

O app abre em `http://localhost:4200`.

## Sobre

Formulário com nome, e-mail, assunto e mensagem, validado com `ngModel` (`required`, `email` e `minlength`).
